## ・概要
ニトリのキッチン周り商品のコーディネート促進のためのコミュニティサイトの新機能。ユーザーによるキッチンコーディネートの投稿を共有する。RoomClipを参考とする。

MVP：画像でキッチンコーディネートを一目見て印象的に映るように表示。商品を探しているユーザーが画像を選択し、投稿の詳細や使われているニトリの商品情報を確認できる。投稿内のアイテム（保存用品、調理道具、台所整理用品、棚など）をニトリアプリ内の商品と紐づけ。

**（今後・余裕があれば実装）Instagram連携**
  - Instagramからの流入や、若年層への波及・拡散を狙った機能。

## ユーザーストーリー
- ターゲット

- いつ

 **どのような流れか**
  1. **探す（一覧表示）：** サイトを開き、おしゃれなキッチンのコーディネート画像を一覧から眺めて好みのものを見つける。
  2. **詳細を見る（詳細表示）：** 気になった画像を選び、詳細ページで使われているニトリの商品を確認する。
  3. **参考にする・購入へ：** 「この配置を真似したい」「このアイテムが欲しい！」と思い、実際の部屋作りやニトリでの買い物に活かす。
 
 
 ## 今開発で着目していること
- 投稿の際、対応する商品をユーザーが選択する必要がある。ここのUIはどうすれば良いか。。 -> 今回はプルダウンで妥協
- タグ検索：タグのジャンル(生活スタイル[一人暮らし, ファミリー]、[料理こだわり, 収納]、カラー[レッド, ブルー, グリーン]、テーマ[モダン, ナチュラル, カフェ])、商品のジャンル[フライパン, 食器棚]


検索(index)の改善をします
・検索として設定済みのタグは検索窓の下に横並びで表示する(モーダルを開かずとも表示する)。同時にタグを追加するボタンもその場所に、現在のタグ検索モーダルの未設定タグと同様のデザインで表示しておく。
・ユーザーが初めてここに訪れた時、モーダルを出してサイズ、場面、テーマ、カラーの4項目について、順番に質問をする形でタグ設定を決めてもらいます。まずサイズについて3つの選択肢と次へボタンを示し、次に行くとモーダル内が次の質問に変わり、場面について4つのタグと次へボタンを示す、、ように繰り返す。
・4項目についてタグを選択してもらえたらモーダルを閉じて検索結果を表示する

ユーザーストーリー
始まりは消費者は必要なものを検索して、口コミを見て、購入に至る

-> 関連商品やコーディネートに結びつけるために、展示(店舗)や関連商品の提案(ECサイト)を行う

(悩み)：たくさん提示されたけと、何を買っていいのかわからない　+ たくさんの組み合わせで商品を家で使うイメージが湧かない
→ 結果として必要な商品単体の購入にとどまる現状

悩みの種は何か、、購買体験における「口コミを見て判断」するところに注目

大筋は、「顧客側のコーディネートを(口コミのように)見ることで、自分に合った納得の併売とコーディネートへの関心を向上」

・商品を単体で見るのではなく、常に使われ方から検索するという変革を起こす。
