## ・概要
ニトリのキッチン周り商品のコーディネート促進のためのコミュニティサイトの新機能。ユーザーによるキッチンコーディネートの投稿を共有する。RoomClipを参考とする。

MVP：画像でキッチンコーディネートを一目見て印象的に映るように表示。商品を探しているユーザーが画像を選択し、投稿の詳細や使われているニトリの商品情報を確認できる。投稿内のアイテム（保存用品、調理道具、台所整理用品、棚など）をニトリアプリ内の商品と紐づけ。

**（今後・余裕があれば実装）Instagram連携**
  - Instagramからの流入や、若年層への波及・拡散を狙った機能。

 **どのような流れか**
  1. **探す（一覧表示）：** サイトを開き、おしゃれなキッチンのコーディネート画像を一覧から眺めて好みのものを見つける。
  2. **詳細を見る（詳細表示）：** 気になった画像を選び、詳細ページで使われているニトリの商品を確認する。
  3. **参考にする・購入へ：** 「この配置を真似したい」「このアイテムが欲しい！」と思い、実際の部屋作りやニトリでの買い物に活かす。
