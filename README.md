---

公開先: [こちら](https://hackathon-2026-summer.vercel.app/)

## ・概要
ニトリのキッチン周り商品のコーディネート促進のためのコミュニティサイトの新機能。ユーザーによるキッチンコーディネートの投稿を共有する。RoomClipを参考とする。

MVP：画像でキッチンコーディネートを一目見て印象的に映るように表示し、商品を探すユーザーは画像を選択して投稿の詳細を確認する。

instaramから若者への波及は余裕があれば実装する

## ユーザーストーリー
- ターゲット
  - キッチンのコーディネートに意欲のある人
  - キッチンに何を置いていいかわからない人
- いつ
  - 新生活で家具などを見る際にニトリで商品を探す時
