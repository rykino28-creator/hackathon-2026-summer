## ・概要
ニトリのキッチン周り商品のコーディネート促進のためのコミュニティサイトの新機能。ユーザーによるキッチンコーディネートの投稿を共有する。RoomClipを参考とする。

MVP：画像でキッチンコーディネートを一目見て印象的に映るように表示。商品を探しているユーザーが画像を選択し、投稿の詳細や使われているニトリの商品情報を確認できる。投稿内のアイテム（保存用品、調理道具、台所整理用品、棚など）をニトリアプリ内の商品と紐づけ。

**（今後・余裕があれば実装）Instagram連携**
  - Instagramからの流入や、若年層への波及・拡散を狙った機能。

## ユーザーストーリー

 **どのような流れか**
  1. **探す（一覧表示）：** サイトを開き、おしゃれなキッチンのコーディネート画像を一覧から眺めて好みのものを見つける。
  2. **詳細を見る（詳細表示）：** 気になった画像を選び、詳細ページで使われているニトリの商品を確認する。
  3. **参考にする・購入へ：** 「この配置を真似したい」「このアイテムが欲しい！」と思い、実際の部屋作りやニトリでの買い物に活かす。

開発の指示
投稿詳細のdetail.htmlやdetail.jsのあたりを以下の要件に従って編集しましょう。
・現在の投稿詳細における「この写真のアイテムをまとめてカートに入れる」は取り除きましょう。
・ピンの種類はニトリ以外の商品が写っている時には、代替のニトリ商品を用いて色を変えて表示しましょう。posts.jsonにニトリの商品と、代替商品を区別して保存しましょう。次の項目にもありますが、一つのピンに対して表示する商品は複数可能にします。
・ピンのついた商品について、現在はopenProductの際に表示するブロックにピンの商品のみが表示されますが、そこに類似商品も示します。データは仮のもので、posts.jsonに加えましょう。
・以上2点についてまとめると、ピンに対して複数の商品を対応させます。その種類はピンそれ自体のニトリ商品、代替商品/類似商品の二つです(「写真に写っている商品」の表示の際には一つの商品を囲う枠の下の色がニトリカラー、または代替商品なら別の色で示して区別します)。openProductの際に表示される商品のブロックについて、類似商品のブロックも縦に並べます、スクロール可能にしています。写真に写っているのがニトリの商品の時には、ニトリの商品+類似商品を、ニトリ以外の商品が写っている時には複数の代替商品を表示します。写真に完全に対応した商品のみ目立たない形でアクセントを入れましょう。
・カートに入れるという選択、また投稿詳細画面の下部には、選択済みの商品の合計金額とを表示し、タップしたらopenProductの時の類似画面で、選択済の商品のモーダル?を表示し、画面の下部に表示し、まとめてカートに入れる動線

アイテム(フライパン)を起点に収納に困っている -> 小物収納の粒度で調べる
キッチンボードを決めている -> 周りの関連商品を調べる(全体のコーディネートで近い雰囲気をみる)
